# API для разработчиков TelegaStars — обновлённая документация

Этот текст предназначен для обновления страницы https://telegra.ph/Dokumentaciya-API-09-27 после установки новой версии бота.

## Как начать

1. В боте откройте «API для разработчиков» → «Получить API». База счёта Antilopay — **145,60 ₽**; при комиссии 3% ориентировочная сумма к оплате **149,97 ₽**. После подтверждения платежа бот пришлёт секретный ключ.
2. В том же разделе откройте «Пополнить баланс API» и выберите 500, 1000, 3000 ₽ или укажите свою сумму от 100 до 100 000 ₽. Сумма зачисления указана в рублях; Antilopay выставляет счёт на базовую сумму `сумма пополнения / 1,03` с округлением до копеек. Проверьте итог с комиссией на странице оплаты. Баланс зачисляется только после подтверждения платежа. Кнопка видна всем, но пополнение доступно после покупки доступа к API.
3. Заказы Stars списывают с баланса **1,38 ₽ за одну звезду**. Платить через СБП за каждый заказ клиента больше не нужно. Плата за доступ к API не поступает на баланс.
4. Используйте ключ только на сервере. При перевыпуске ключа в боте старый ключ сразу отключается.

Адрес API: `https://bot-1788890713-7094-andrey510913.bothost.tech/api/v1`. Все запросы — HTTPS и JSON. Передавайте `Authorization: Bearer ВАШ_КЛЮЧ`.

## Проверить баланс

`GET /api/v1/balance`

Ответ:

```json
{"balance_rub":"500.00","currency":"RUB"}
```

## Создать заказ Stars

`POST /api/v1/stars/orders`

Дополнительные заголовки: `Content-Type: application/json` и `Idempotency-Key: УНИКАЛЬНЫЙ_КЛЮЧ` (8–100 латинских букв, цифр, `_` или `-`). Если запрос прервался, повторите его **с тем же ключом и теми же параметрами**: повторная попытка не спишет деньги ещё раз.

Тело:

```json
{"username":"@exampleuser","stars":100}
```

`username` — публичный username получателя: `@` и 5–32 латинских букв, цифр или `_`. `stars` — целое число от 50 до 1000. За 100 звёзд списывается 138,00 ₽.

Пример вызова:

```bash
curl -X POST 'https://bot-1788890713-7094-andrey510913.bothost.tech/api/v1/stars/orders' \
  -H 'Authorization: Bearer ВАШ_КЛЮЧ' \
  -H 'Idempotency-Key: order_100_001' \
  -H 'Content-Type: application/json' \
  -d '{"username":"@exampleuser","stars":100}'
```

Ответ (HTTP 201 при новом заказе, HTTP 200 при повторе):

```json
{"order_id":123,"status":"paid","username":"@exampleuser","stars":100,"charged_rub":"138.00","currency":"RUB","balance_rub":"362.00"}
```

Бот начинает доставку после списания. Ответ `paid` означает, что деньги с внутреннего баланса зарезервированы; дождитесь `done` перед уведомлением своего клиента об успешной выдаче.

## Статус заказа

`GET /api/v1/stars/orders/123` с тем же заголовком авторизации. Доступен только заказ, созданный вашим ключом. В ответе: `order_id`, `status`, `username`, `stars`, `charged_rub`, `currency`.

Статусы: `paid` — сумма списана, заказ ждёт обработки; `processing` — выполняется; `done` — звёзды отправлены; `needs_moderation` — ручная проверка, сумма остаётся закреплённой за заказом; `balance_refunded` — после проверки сумма возвращена на баланс. Если заказ долго остаётся в `processing` или `needs_moderation`, сообщите поддержке `order_id`. Не создавайте новый заказ для того же клиента, пока не выяснили результат предыдущего.

## Недостаточно денег

Если средств не хватает, API возвращает HTTP 402 и JSON:

```json
{"error":"insufficient_balance","required_rub":"138.00","balance_rub":"50.00"}
```

Заказ не создаётся и деньги не списываются. Бот также отправляет разработчику сообщение с предложением пополнить баланс (не чаще одного раза в минуту). После пополнения повторите запрос с тем же `Idempotency-Key`.

Другие ошибки: `400` — неверный JSON или параметры; `401` — неверный ключ; `404` — заказ не найден; `409` — конфликт повторного ключа или получатель недоступен; `429` — слишком частые запросы; `503` — продажи временно приостановлены. Заказы выполняются через общий механизм доставки бота и подчиняются ограничениям для получателей.

По вопросам оплаты и выдачи обращайтесь в поддержку через бот. Никогда не передавайте API-ключ клиентским приложениям или третьим лицам.
